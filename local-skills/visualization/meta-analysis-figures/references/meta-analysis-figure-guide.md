# 系统综述与 Meta 分析图件参考

本文件解释四个脚本背后的规范，以及**哪些结论不能从图上直接下**。画图容易，把图读对很难。

---

## 一、PRISMA 2020 流程图的计数逻辑

### 1.1 三个必须区分的名词

| 名词 | 含义 | 常见错误 |
|---|---|---|
| **记录 Record** | 数据库里的一条题录 | — |
| **报告 Report** | 一份文献（一篇论文、一份会议摘要） | 把报告数当研究数 |
| **研究 Study** | 一个独立的研究（可能由多份报告描述） | 把一篇含两个队列的论文算成两项研究 |

**一篇论文可以报告两项研究，一项研究也可以有多份报告。** 所以
「全文评估 138 份报告 → 纳入 24 项研究」这种数字关系是正常的，
`assessed ≠ included + excluded` 不一定是错误——本技能的 `prisma_flow.py`
因此在计数不一致时**只提醒、不拒绝**；真正会导致拒绝出图的是
「纳入数 > 全文评估数」这类**物理上不可能**的关系。

### 1.2 各框之间的数量约束

```
records screened   = records identified − records removed before screening
reports sought     = records screened   − records excluded
reports assessed   = reports sought     − reports not retrieved
studies included  <= reports assessed   − reports excluded
```

`records removed before screening` 通常由三部分构成：重复记录、自动化工具判定为
不合格的记录、其他原因移除的记录。三者都应在流程图中列出具体数字。

### 1.3 排除理由必须写全

PRISMA 2020 要求「reports excluded」下逐条列出**理由与条数**，且理由要具体到能复现
判断，例如 `Wrong population (n = 52)` 而不是 `Not relevant (n = 52)`。
理由之和应当等于全文排除总数——本技能会校验这一点。

> 筛选标准必须在筛选**开始前**写定。中途改标准要明说并重筛，不能悄悄改。

## 二、森林图的必备要素

一张能过审的森林图至少要有：

1. **每项研究的标签**（第一作者 + 年份，与参考文献一致）
2. **效应量与 95%CI 的图形**：点 + 横线，横线两端带帽
3. **权重表达**：方块面积正比于权重（本技能按 `weight` 列实现）
4. **无效线**：比值类（HR / OR / RR）在 1；差值类（MD / SMD）在 0
5. **合并效应量**：菱形，宽度即其 95%CI
6. **右侧数值列**：`0.79 (0.71–0.88)` 形式，与图形一一对应
7. **横轴标签**：写明效应量类型，如 `Hazard ratio (95% CI)`
8. **方向标注**：`← Favours metformin` / `Favours control →`
9. **模型说明**：固定效应还是随机效应（写进图注或轴标签）
10. **异质性指标**：I²、τ²、Cochran Q 的 p 值（写进图注）

### 2.1 对数轴还是线性轴

| 效应量 | 轴 | 无效线 |
|---|---|---|
| HR / OR / RR / IRR | **对数** | 1 |
| MD / WMD / SMD / 均数差 | 线性 | 0 |

**比值类必须用对数轴。** 线性轴上的比值会让人误判——0.5 和 2.0 在保护方向上
离 1 一样远，线性轴画出来却一长一短，视觉上就在骗人。本脚本用 `--log` 强制，
也会在未指定时按数值自动判断。

### 2.2 亚组的两个陷阱

- **亚组分析是探索性的**，不能当作确证性结论。亚组间差异要检验交互作用
  （如 `p for interaction`），不能只看"这一组显著、那一组不显著"。
- 亚组数量越多，假阳性越多。预设亚组（写进方案）与事后亚组要分开说。

## 三、漏斗图与发表偏倚

### 3.1 怎么读

横轴效应量，纵轴标准误（**向下增大**，精度高的研究在顶部）。
若无偏倚，点应大致对称地分布在一个倒漏斗形内，顶部密集、底部散开。

### 3.2 四个必须说清的边界

1. **k < 10 不要做检验。** Cochrane 手册的建议是纳入研究少于 10 项时，
   不对称性检验功效不足。本脚本会把这个提醒打到图上，并且**必须留在图里**。
2. **不对称 ≠ 发表偏倚。** 其他原因同样造成不对称：
   - 真实的效应量随研究规模变化（如小研究人群不同）
   - 方法学质量与样本量相关
   - 效应量的固有特性（OR 在小样本上天然偏大）
   - 偶然性
3. **Egger 检验对二分类结局有已知偏倚。** Egger 回归用 `est/se` 对 `1/se` 回归，
   检验截距是否为 0。对 OR / RR 这类比值效应量，标准误与效应量本身相关，
   Egger 检验会失效——此时应改用 Harbord 检验。
4. **连续变量结局要用 Peters 检验。** 连续结局下标准误与均数差相关，
   Egger 检验假阳性率高。

> 本脚本的 Egger 实现是**标准形式**，用于加一个数字，不是用来下结论的。
> 报告时写「Egger 检验提示存在小样本效应（p = …），但不能排除异质性等
> 其他来源」，而不是「存在发表偏倚」。

### 3.3 本脚本的合并线怎么来的

`--pooled` 未指定时，用**固定效应逆方差法**算一个参考中心：

```
w_i = 1 / se_i²
pooled = Σ(w_i · est_i) / Σ w_i
```

这只用于给漏斗图定中心线。**正式报告的合并效应量应当用你 Meta 分析脚本的
结果**（随机效应模型等），并通过 `--pooled` 传进来，保证图与正文数字一致。

## 四、偏倚风险评价

### 4.1 Cochrane RoB 2（随机对照试验，五个域）

| 域 | 要回答的问题 |
|---|---|
| 1. 随机化过程 | 分配序列是否随机、是否做到分配隐藏、基线是否可比 |
| 2. 偏离既定干预 | 受试者/实施者是否知晓分组、是否有影响依从性的因素；分析是否遵循 ITT |
| 3. 结局数据缺失 | 缺失比例、缺失原因是否与结局相关、是否有恰当的处理 |
| 4. 结局测量 | 测量方式是否因分组而不同、评价者是否知晓分组 |
| 5. 结果选择性报告 | 是否有预注册方案、报告的结果与分析方案是否一致 |

判定三档：**低风险 / 有一些担忧 / 高风险**。

注意域 2 和域 4 要**分别对「干预效应」和「依从效应」两种关注点**做判定，
本脚本用一位取值表示，需要做双评价时把两套判定分成两组列。

### 4.2 ROBINS-I（非随机干预性研究，七个域）

混淆、参与者选择、干预分类、偏离既定干预、缺失数据、结局测量、结果选择性报告。

判定五档：**低 / 中等 / 严重 / 极严重 / 无信息**。
本脚本的 `--tool robins-i` 只切换默认域标签；由于级别更多，
建议在正文中另附一张逐研究的判定理由表（红绿灯图只表达结论，不表达依据）。

### 4.3 红绿灯图的读法

- **纵向**读：看某研究的整体质量是否**全绿**——只要有一个红，就要在敏感性分析里
  单独剔除该研究看结果是否稳健。
- **横向**读：看某个域是否普遍有问题——如「结局测量」全红，说明该领域所有研究
  都缺盲法，这是**证据体的系统局限**，要写进局限性，而不是归咎单项研究。
- 红绿灯图**不显示权重**。样本量小的低质量研究和高权重研究在图上长得一样，
  别把格子数当权重看。

## 五、导出与排版

- **矢量优先**：PDF / EPS / SVG。森林图与流程图都是矢量图形，导出位图会在排版时糊掉。
- **位图备用**：TIFF / PNG，≥300 dpi（线条图期刊常要求 600–1200 dpi）。
- **字体嵌入**：本技能已设 `pdf.fonttype = 42`，避免期刊排版端提示字体缺失。
- **栏宽**：用 `--journal` / `--span` 先按目标刊的近似栏宽设定；投稿前以该刊
  最新 Author Guidelines 复核。更完整的尺寸、字号与配色规范见上游
  `scientific-visualization` 技能。
